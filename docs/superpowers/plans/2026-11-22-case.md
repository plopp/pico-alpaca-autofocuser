# Focuser Case Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A build123d script that generates the printable case (body, front plate, lid, key) for the NEMA 17 + carrier PCB unit, with STL/STEP files, preview images and tests.

**Architecture:** `case/params.py` holds every dimension in one coordinate frame, the **board frame**: x from the board's rear edge (0) towards the motor, y from the board's top long edge (0 to 50), z up from the board's top surface. `case/parts.py` builds each part from those numbers; `case/build.py` exports them. Tests build the parts and check them with solid intersections and point containment, so no test depends on how a part was modelled.

**Tech Stack:** Python 3.12 in `.venv`, build123d 0.13 (OpenCascade), matplotlib for preview PNGs, pytest.

**Spec:** `docs/superpowers/specs/2026-11-22-case-design.md`

## Global Constraints

- Board v1.0 geometry is fixed (ordered): 80 × 50 × 1.6 mm, rear edge x = 0. Values that come from the PCB are cross-checked against the committed board in a test.
- Rear wall exactly 2.0 mm thick (x = −2.0…0): J1 front and J3 nose end flush with its outside.
- NEMA 17 up to 48 mm body length; 42.3 mm square; 4 × M3 on 31 mm square; Ø22 boss; Ø5 shaft.
- Camera thread: 1/4"-20 hex nut, 11.1 mm across flats, 5.6 mm thick, embedded by a print pause (no access).
- Ridge (key) width is a parameter, default 6.0 mm; it runs across the case (along y).
- Print clearance 0.3 mm unless stated. M3 heat-set inserts: Ø4.0 hole, 5.0 mm deep.
- Plastic only over the Pico's antenna end (x 43–53).
- Commits on branch `case` (from `pcb-temp-jack-rear`, which has the board v1.0 the case is built around), ending with `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`.

## Review Focus

- **A real Pico with headers sits higher or lower than 13.3 mm** → the plug must still reach: `test_usb_hole_tolerates_height` checks a 7 × 2.5 mm micro-B plug fits anywhere in z 12.3…14.3.
- **A 34 mm motor** → nothing must rely on the motor's rear face (the board stop is on the lid, not the motor): `test_board_stop_independent_of_motor`.
- **The Arca plate's captive screw is longer than expected** → the screw hole above the nut must not break into the motor compartment: `test_screw_hole_is_blind` (solid material between nut top and plinth top).
- **The key printed at a different width** → the groove must accept a key up to `KEY_W + CLEAR`: `test_key_fits_groove`.
- **The lid screwed down on the TMC2209 heatsink** → envelope test with the module at 22 mm: `test_parts_clear_board_envelope`.
